Scope: Hermes Agent is a general autonomous agent. This placemat covers its CLI and TUI coding surface only — its messaging, voice and desktop surfaces are deliberately left out. See the full documentation for those.

TUI & Symbols

Keybindings
ItemDescription
#Ctrl+POpen the fuzzy command palette
  • Type to filter commands and skills, ↑/↓ to move, Enter inserts into the composer — it never auto-runs.
  • Also reachable as /palette.
#Ctrl+TExpand the live-subagent dock into the full /agents roster
  • On a selected worker: Enter or t for its transcript, d for details, e to steer, x to stop.
  • The dock fits its row count to terminal height and preserves your composer draft.
#Ctrl+XOpen the live session switcher
  • With a queued message highlighted it deletes that message instead; Esc cancels without deleting.
  • Inside the switcher: Ctrl+D closes the selected session, Ctrl+N starts a blank one, Ctrl+R refreshes the list.
#Ctrl+G / Ctrl+X Ctrl+EOpen the input buffer in $EDITOR for long prompts
  • Save and exit sends the contents back as the prompt.
#Ctrl+VPaste text, falling back to clipboard image attach
  • Tries normal text paste, then OSC52 / native clipboard reads, then image attach when the payload resolves to an image.

Transcript symbols
ItemDescription
#❯Input prompt — where you type
  • Themeable: a skin can set its own prompt symbol, and ┊ (the tool-activity rail) follows tool_prefix.
#●A tool call; the bullet precedes the tool name and arguments
  • ✓ / ✗ are appended when the tool result succeeds or fails.
#▸ / ▾Collapsed or expanded section chevron
  • Used for thinking, tools, subagents and banner sections; click to toggle.
#▍Streaming cursor — blinks while the model is still emitting text
#│ / ├─ / └─Tree rails connecting a parent to its children
  • └─ marks the last child.
  • Inline markers: ◈ a display-only timeline event, ◇ an injected reference block, ↳ the sticky prompt echoing the message being worked on.

Status bar
ItemDescription
#⏱ / ⏲Per-prompt elapsed time while the turn runs
  • Shows turn time over session time, e.g. ⏱ 12s/3m 45s; ⏲ is the same timer frozen after the turn.
#cmp N / ▶ N / ⛓ N / N bgSession counters
  • cmp N auto-compressions so far, ▶ N running /bg tasks, ⛓ N active subagents, N bg tracked background terminals.
#⚠ YOLOYOLO mode is on — dangerous commands auto-approve
#◉ focusFocus view is on (reduced output)
  • Pinned so it never drops off a narrow terminal.

Overlays & prompts
ItemDescription
#⚠ approval requiredA tool needs your explicit yes
  • Rendered as a bordered panel with the command preview.
  • 🔐 is a masked sudo prompt and 🔑 a masked credential prompt.
#○ / ■ / ⌛Subagent states in the /agents overlay
  • ● running, ○ queued, ✓ completed, ■ interrupted, ✗ failed, ⌛ timed out, ⚠ errored.
  • ⚡N rolls up N active agents; ▁▂▃▄▅▆▇█ is an activity sparkline.
#✎ draftThat session’s composer holds an unsent draft
  • Session switcher states: ✓ idle, … starting, ? waiting for input, ▶ working.

Slash Commands (Core)

Session
ItemDescription
#/new / /resetStart a new session with a fresh id and history
  • An optional name sets the initial title; append now, --yes or -y to skip the confirmation modal.
#/clearClear the screen and start a new session
#/resumeResume a previously-named session
#/sessions / /switchBrowse and resume previous sessions
  • In the TUI this opens the live session switcher; /sessions new starts another live session.
#/branch / /forkBranch the current session to explore a different path
#/history / /saveShow conversation history, or save the conversation
#/titleSet a title for the current session
#/undo / /retryRemove the last exchange, or resend the last message
#/prompt / /composeCompose the next prompt in $EDITOR as markdown
#/quit / /exitExit the CLI

Context & history
ItemDescription
#/compressManually compress context — flush memories and summarise
  • /compress here [N] keeps the most recent N exchanges verbatim (default 2) so you pick the boundary.
  • A focus topic narrows what a full summary preserves.
#/context / /ctxVisual context-window breakdown
  • A glyph grid where each cell is about 1% of the model window, plus a per-category table.
  • /context all adds per-skill and per-toolset cost listings.
  • Read-only and computed locally — no LLM call, no prompt-cache impact.
#/statusSession info plus a locally-computed session recap
  • Model, provider, profile, session id, working directory, title, timestamps, token totals and agent state.
#/usageToken usage, cost breakdown and session duration
  • Adds an Account limits section when the active provider exposes quota live.

Coding workflow
ItemDescription
#/diffShow git changes in the working directory
  • Default is unstaged changes plus untracked files; staged, all and session widen the scope.
  • session is the cumulative diff of everything Hermes changed here and needs checkpoints enabled.
  • --stat prints just the changed-file summary; path arguments restrict it.
#/rollbackList or restore filesystem checkpoints
#/snapshot / /snapCreate or restore snapshots of Hermes config and state
  • create [label], restore <id>, prune [N], or list with no arguments.
  • Database restores use SQLite’s backup API; if another process still holds the database, the restore refuses rather than risk corruption.
#/worktreeInspect or create isolated git worktrees mid-session
  • CLI only. /worktree new [name] creates one under .worktrees/ from the freshly-fetched remote tip and retargets the session’s terminal and file tools into it.
  • Named trees use hermes/<name>; unnamed ones get a random hermes-<id>.
  • On exit the tree is kept only if it has unpushed commits — the same lifecycle as hermes -w.
#/planWrite a markdown implementation plan to .hermes/plans/
  • Planning only, no execution; an empty argument infers the task from the conversation.
#/initGenerate or update AGENTS.md from a repo scan
  • Merge-updates an existing file rather than overwriting it; optional notes steer the emphasis.
#/reviewSpawn an independent full-privilege reviewer subagent
  • It investigates in the background and its review re-enters the session as a background-subagent completion.
  • Pin a dedicated model with auxiliary.review in config.yaml.

Run control
ItemDescription
#/queue / /qQueue a prompt for the next turn without interrupting
#/steerInject a mid-run note delivered after the next tool call
  • Appended to the last tool result once the current tool completes — no interrupt, no new user turn.
#/stopKill all running background processes
#/bgRun a prompt in a separate background session
  • Your current session stays free; results appear as a panel when the task finishes.
#/btwAsk a quick side question about the current conversation
  • A one-shot auxiliary call against a read-only transcript snapshot — history and prompt cache untouched.
  • For independent work with a fresh context use /bg instead.
#/agents / /tasksShow active agents and running tasks
#/moaRun one prompt through the default Mixture of Agents preset
  • One-shot — your session model is restored afterwards.
#/busyControl what happens when you message mid-turn
  • Choices are queue, steer and interrupt.

Slash Commands (Tools)

Model & reasoning
ItemDescription
#/modelShow or change the current model
  • Accepts provider:model, custom:model, and user-defined aliases.
  • Flags: --global persists, --session forces session-only, --once applies to the next turn, --refresh re-fetches the model list.
  • Only switches between already-configured providers — run hermes model to add one.
  • Switching mid-conversation resets the prompt cache, so the next turn re-reads at full input price.
#/reasoningManage reasoning effort and display
  • Levels: none, minimal, low, medium, high, xhigh, max, ultra.
  • show/hide toggle display, full and clamp adjust it, --global persists the effort.
#/fastToggle provider priority processing
  • fast every request, auto only the first agent.fast_auto_seconds of a turn, cold that window on the first turn only.
#/codex-runtimeToggle the optional Codex app-server runtime for OpenAI models
  • codex_app_server hands turns to a codex app-server subprocess for native shell, apply_patch and migrated Codex plugins.
  • Takes effect on the next session.
#/personalitySet a predefined personality; none clears the overlay

Tools & skills
ItemDescription
#/toolsList, disable or enable tools for this session
  • Disabling a tool removes it from the agent’s toolset and triggers a session reset.
#/toolsetsList available toolsets
#/skillsSearch, install, inspect and manage skills
  • Also the review surface for the write-approval gate: pending, diff, approve, reject, approval on|off.
#/bundlesList skill bundles — /<name> aliases that preload several skills
#/learnDistil a reusable skill from a directory, URL, workflow or notes
  • The agent gathers the sources itself and authors a SKILL.md.
#/memoryReview pending memory writes and toggle the write gate
#/refineRun the background memory and skill self-improvement review now
  • Runs in a background fork against a conversation snapshot; the live session and prompt cache are untouched.
#/reload-skillsRe-scan the skills directory for installed or removed skills
#/reload-mcpReload MCP servers from config.yaml and re-probe tools
#/reloadReload .env into the running session
  • Picks up new API keys without restarting.
#/pluginsList installed plugins and their status
#/browserAttach browser tools to a running Chromium-family browser over CDP
  • connect defaults to http://127.0.0.1:9222; disconnect detaches; status shows the connection.

Display & safety
ItemDescription
#/yoloToggle YOLO mode — skip all dangerous-command approval prompts
#/approvalsShow or set the persistent approval mode
  • Modes are manual, smart and off.
#/focusReduced-output view showing only your prompt and the final response
  • Composes with /verbose: it snaps progress to off and restores your mode afterwards.
  • Nothing is sent differently to the model — detail is hidden, never discarded.

Profile & account

Skills, Context & Subagents

Context files
ItemDescription
#.hermes.md / HERMES.mdProject instructions, highest priority
  • Walks up to the git root.
#AGENTS.mdProject instructions, conventions and architecture
  • Inside a git repo Hermes loads a merged chain from the git root down to your working directory, so deeper files take precedence.
  • Each file gets a provenance header and identical copies along the chain are deduplicated.
  • Outside a repo only the working directory is checked, so a stray file in /tmp or $HOME cannot leak in.
#AGENTS.override.mdPersonal per-directory override, usually gitignored
  • Loaded instead of a neighbouring AGENTS.md.
#CLAUDE.mdClaude Code context files are detected too
#.cursorrules / .cursor/rules/*.mdcCursor IDE coding conventions, from the working directory only
#SOUL.mdGlobal personality and tone for this Hermes instance
  • Loaded only from HERMES_HOME, always, as agent identity slot #1 — independent of the project chain.
  • Seeded automatically if it does not exist.
#first match winsOnly one project context type loads per session
  • Order: .hermes.md → AGENTS.override.md → AGENTS.md → CLAUDE.md → .cursorrules.
#progressive discoverySubdirectory context files are injected as the agent navigates into them
#--ignore-rulesSkip auto-injection of context files, memory and preloaded skills

Automation & MCP

Scheduled & recurring
ItemDescription
#/cronManage scheduled tasks from chat
  • List, add, edit, pause, resume, run and remove.
#/heartbeat / /hbA recurring prompt that re-enters this session when idle
  • Minimum interval 60 s, and missed ticks coalesce.
  • Session-scoped and in-process — use hermes cron for durable isolated schedules.
  • Subcommands: status, pause, resume, clear.

Goals & loops
ItemDescription
#/goalA standing goal Hermes works toward across turns
  • After each turn an auxiliary judge decides DONE or CONTINUE; if not done, Hermes auto-continues.
  • Budget defaults to 20 turns (goals.max_turns); any real user message preempts the loop and state survives /resume.
  • Subcommands: status, pause, resume, clear.
#/subgoalAppend a criterion to the active goal mid-loop
  • The judge factors every subgoal in, so the goal is not done until the original and all subgoals are met.
  • Requires an active /goal.

Suggested & templated automation
ItemDescription
#/suggestions / /suggestReview suggested automations
  • accept <id> creates the proposed automation, dismiss <id> rejects one, catalog adds curated starters, clear clears resolved records.
#/blueprint / /bpSet up an automation from a template
  • Bare lists the catalog, a name starts a guided slot-filling flow, and name slot=value creates the job directly.
