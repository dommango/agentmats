October 2026 v0.21.6 – v0.22.4 7 releases

Hermes Agent v0.22.4 2026-10-21

  • FIXhermes plugins — installing a plugin with no dependencies no longer shows an empty consent prompt

Hermes Agent v0.22.3 2026-10-21

  • ADDhermes plugins — update <name> re-pins that catalog install to the reviewed SHA; omitting the name updates everything installed (--yes skips confirmation)
  • CHGMCP tool calls now show live progress notifications in the CLI/TUI while a long-running call is in flight
  • CHGThe local runtime adds Nemotron 3.5 Bolt model support and single-slot DFlash draft decoding

Hermes Agent v0.22.2 2026-10-15

  • CHGv0.22.2 replaces v0.22.1, which was built from the wrong commit and shipped unreleased gateway work; a session that ran under the v0.22.1 gateway can't be deleted from v0.22.2 (known issue)
  • FIXA supervised gateway (systemd, launchd or Docker) could refuse to start after a reboot because of a stale recorded process ID
  • CHGLong local-model turns on laptops get clearer progress display, sleep-aware stall timers, retry handling after server recovery, and corrected memory sizing on Windows unified-memory machines

Hermes Agent v0.22.1 2026-10-14

  • ADDsecurity.allow_lazy_installs settings key — gate on-demand dependency installation; already-installed dependencies stay usable when set to false
  • CHGhermes pm — its gc subcommand is promoted from unverified; confirmed in the package-management reference as removing unreferenced tool-store entries, download partials, unused Python generations and deleted-checkout state

Hermes Agent v0.22.0 — The Threshold Release 2026-10-13

  • ADDhermes pm — unified manager for Hermes's pinned Python, Node and other tool dependencies, with doctor, status and repair subcommands; the release notes also name a gc subcommand, not yet confirmed in the CLI reference
  • ADDhermes usage — show the account's rate-limit windows without starting a session; --provider <name> picks the account, --json emits machine-readable output
  • ADDhermes auth — the v0.22.0 release notes name a new upgrade subcommand, alongside /login, converting a free trial identity into a full Nous account; not yet confirmed in the CLI reference
  • ADDhermes mcp — login <server> --flow device forces RFC 8628 device-code authorization instead of browser PKCE, for headless logins
  • ADDhermes sessions — new repair-profiles / repair-prompts subcommands settle session, routing and platform state stuck under the wrong profile, and report system prompts degraded by a since-fixed maintenance-compaction bug
  • ADDagent.auto_recovery_cycles, agent.text_verbosity and agent.turn_liveness.timeout_s settings keys — outage recovery cycles, final-answer length for Responses-API models, and a stalled-turn watchdog
  • ADDdisplay.bell_on_prompt settings key — terminal bell, plus an OSC 9 desktop notification, when a blocking prompt opens
  • CHGBuilt-in tool names — todo, cronjob and process renamed to todo_list, cronjob_manage and process_manage; the old names still work
  • FIXhermes plugins — plugins list and the plugin catalog now make at most one live catalog request per load; enabling a plugin no longer strips core tools; a platform whose plugin fails at startup is flagged in hermes status and recovers without a restart
  • FIXA parked OAuth MCP server no longer replays its dead refresh token every session
  • FIXThe gateway /goal add gate no longer lets non-admin users reach the host shell
  • FIXAutomatic git calls from kanban, worktree cleanup and subagents no longer run a cloned repository's own hooks or filters
  • FIXQwen models behind Alibaba's content guardrail now end the turn with the safety notice instead of retrying
  • FIXResizing the CLI no longer re-appends the conversation to scrollback

Hermes Agent v0.21.7 2026-10-12

  • ADDhermes update — adds --set-channel <stable|main> to persist the update channel, --channel <stable|main> to override it for one run, and --branch <name> to pin a branch; source installs default to stable (the latest release's exact commit), forks and mirrors default to main
  • FIX--resume (hermes chat --resume/-r) — signed reasoning (thinking) content now replays when resuming a session, and on the next gateway turn; Bedrock Converse reasoning models are no longer rejected on resumed sessions
  • FIXhermes update on the main channel no longer fails behind regional firewalls that blocked the release-record fetch with a 403; the stable check now uses a configured GitHub token (GITHUB_TOKEN or gh auth login) and reports a GitHub rate limit as a rate limit instead of a generic failure

Hermes Agent v0.21.6 2026-10-08

  • CHGv0.21.6 is the first release cut by Hermes's new stable-release pipeline; it ships a plain semver tag (v0.21.6) with no separate date tag, unlike earlier releases
  • CHGhermes model — adds a Local models entry that installs a managed llama.cpp engine and runs open models fully on-device
  • ADDlocal_runtime.enabled / local_runtime.backend / local_runtime.detect_ports settings keys — configure the managed local-model server
  • CHGhermes status — now prints a one-screen summary by default; --full (alias --all) and --deep expand it
  • CHGhermes cron — cron status/cron list now warn when the cron store isn't writable, and hermes doctor flags it too
  • CHGhermes kanban list — adds --workflow-template-id and --current-step-key filters on two columns v1 stores but doesn't act on; routing logic ships later
  • ADDplugins.isolation settings key — runs third-party plugins in an isolated per-profile host process instead of importing them into the main process
  • FIXAutomatic git calls (session workspace snapshot, subagent worktrees, kanban, worktree cleanup, hermes -w) could run clean/smudge/process filter programs defined by an untrusted repository's own config before the first prompt
  • CHGmcp.discovery_concurrency settings key — promoted from unverified; confirmed default 4, 0 means unlimited

Hermes Agent v0.21.4 (2026.9.21) 2026-09-21

  • ADD--format stream-json — structured JSONL output for a scripted hermes chat -q run, one event object per stdout line
  • ADDskills.auto_load settings key — pin named skills to load into every new session's prompt
  • ADDhermes sessions set-journal-mode — convert state.db's SQLite journal mode after every Hermes process for the profile stops
  • ADDmcp.discovery_concurrency settings key (unverified) — named in the release notes as a configurable MCP discovery connect cap, not yet in the reference docs

Hermes Agent v0.21.3 (2026.9.14) 2026-09-14

  • ADD/loop (alias /proactive) — re-run a prompt on a recurring interval within a session, with --times/--until and status/pause/resume/stop subcommands
  • ADDdisplay.vim_mode settings key — CLI-only vi/vim keybindings for the input composer
  • CHG/queue — bare invocation now lists the pending queue; added list, edit, rm, move and clear subcommands, plus a force-queue add
  • CHG/model — added a --reasoning <level> flag and OpenRouter account-preset selection (@preset/<slug>)
  • CHGhermes auth — OpenRouter credentials can now be added via OAuth browser login (PKCE), alongside the existing API-key flow
  • CHGhermes backup — exclusions expanded to cover regenerable models/, runtimes/ and node/ downloads, more of cache/, and Unix sockets, devices and symlinks
