Slash Commands (Core)

Session lifecycle
ItemDescription
#/helpOpen the help panel of commands and shortcuts
#/exit / /quitClose the TUI session and restore your host shell
#/clear / /newResets active conversation contexts, not just the display
  • Clears the terminal AND wipes the model's context for that thread — closer to starting fresh than a scrollback clear.
#/rewind / /undoRoll back conversation history to a previous message
  • Reverts workspace files to the matching snapshot as well as the transcript; 1.2.6 fixed the lookup sweeping back to an older snapshot and silently overwriting kept work, and skips the elided diff of any edit over 1 MiB.
  • Since 1.2.9 each step shows a relative timestamp, and the panel focuses the most recent step when it opens.
#/fork / /branchClone the current conversation thread into a new parallel session

Slash Commands (Tools)

Tools & tasks
ItemDescription
#/agentsOpen the Agent Manager Panel for background subagents
  • Since 1.2.9 typing @<subagent> <message> sends a message directly to a subagent's conversation, with autocomplete listing running and completed subagents.
#/artifactOpen the Artifact Review Panel
  • Since 1.2.7 LaTeX math ($$...$$, fenced math/latex/tex blocks) and Mermaid diagrams render inline via Kitty graphics, with a Unicode ASCII fallback and Left/Right arrow panning for wide diagrams; press m to cycle Image, ASCII, and Raw views.
  • 1.2.9 added a footer hint when a wide diagram overflows the window, pointing at the Left/Right pan keys.
#/hooksBrowse active pre-flight/post-format script hooks
  • Since 1.2.3 the listing includes hooks bundled inside enabled plugins.
#/mcpOpen the Model Context Protocol server manager
#/skillsBrowse loaded local and global Agent Skills
  • /skills reload (1.2.4) re-discovers skills and slash commands asynchronously, without restarting the session or blocking input.
#/tasksOpen the Task Manager Panel for background shell logs
  • Since 1.2.5 a task sent to the background with an explicit name keeps it in completion notifications and the task list.

Utilities

  • /copy btw (1.2.3) copies the full text of the active /btw side-question response even when its card is collapsed; typing /copy shows argument ghost hints.

CLI & Subcommands

Session flags
ItemDescription
#agyLaunch an interactive Antigravity CLI coding session
#-c / --continueContinue the most recent conversation session
#--conversation <id>Resume a previous conversation by its unique ID
#-p / --print / --promptRun prompt non-interactively and print response to stdout
  • Since 1.2.6 an agent or model API failure prints a structured AGY_ERROR: {...} JSON line on stderr (status, HTTP/gRPC code, retryability, error ID) and exits with code 3 instead of 1.
  • 1.2.9 fixed these runs leaving daemon background processes running past exit, which could hang scripts reading the CLI's output until end-of-file; daemon processes now terminate when the run ends.
#-i / --prompt-interactiveExecute initial prompt and continue interactive session
#--model <name>Specify model for current CLI session
#--effort <level>Set reasoning effort for session (low, medium, high)
#--mode <mode>Set agent execution mode (accept-edits, plan)
#--remote-controlStart the session with a Remote Control connection for another device
  • Introduced in 1.2.6 per the release notes; not present in the 1.2.2 --help this card was verified against. See /remote-control.

Piping & output
ItemDescription
#--input-format <fmt>Input format for print mode (text, stream-json)
  • stream-json reads NDJSON messages from stdin per turn; requires matching output format.
#--output-format <fmt>Output format for print mode (text, json, stream-json)
#--json-schema <schema>Enforce structured output using JSON schema string or file
#--print-timeout <dur>Timeout for a print-mode run; unset, the run continues until the response completes
  • Before 1.2.6 headless runs defaulted to 5m0s; pass this flag explicitly to impose a limit.
  • 1.2.9 fixed background tasks being canceled about 5 seconds after the agent went idle; runs now wait for background tasks until this deadline, capped at 30 minutes.
#--disable-slash-commandsDisable slash command and skill expansion in print mode
#--log-file <path>Override CLI log file path

Environment Variables

Authentication
ItemDescription
#GEMINI_API_KEYAuthenticate with a Gemini API key instead of Google sign-in
  • Also set modelProvider: "gemini" in settings.json; suits headless and CI runs. The CLI reads this credential only from the environment, not from .env files.
  • Since 1.2.6 headless runs authenticated this way keep daemon background commands, such as dev servers, running after the turn finishes; they still terminate once the run itself exits (see -p).
#GOOGLE_GEMINI_BASE_URLPoint the CLI at a different Gemini-compatible endpoint

Rules & Skills

Project rules
ItemDescription
#~/.gemini/GEMINI.mdGlobal rules applied across every workspace
#.agents/rules/*.mdWorkspace-level rule files, 12,000 characters each
  • Backward-compatible with the older .agent/rules path.
  • Since 1.2.7 user and workspace rules get a dedicated 20,000-token budget, cutting oversized rules on newline boundaries, so large rule sets no longer evict skills, workflows, subagents, or MCP tools.
#Manual / Always On / Model Decision / GlobThe four rule activation modes
  • Manual is @-mentioned; Always On always applies; Model Decision lets the agent judge relevance; Glob matches a file pattern like src/**/*.ts.

Custom skills
ItemDescription
#.agents/skills/<name>/SKILL.mdWorkspace-level skill definition with YAML frontmatter
  • Workspace customizations in .agents/ override global and built-in skills.
#~/.gemini/config/skills/Global machine-wide custom skills directory
#progressive disclosureOnly a skill's name and description load until it's activated
  • The agent decides from context whether a skill is relevant, then reads the full SKILL.md before following it.
