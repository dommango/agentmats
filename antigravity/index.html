  • /skills reload (1.2.4) re-discovers skills and slash commands asynchronously, without restarting the session or blocking input.
  • 1.2.16 fixed the / menu listing built-in skills that the current agent does not enable, which had inserted instructions for tools the agent could not use when one was selected.
#/plugin / /pluginsOpen the interactive Plugins Manager, or run install/enable/disable/list inline
  • Since 1.2.11 a plugin placed directly in ~/.gemini/config/plugins whose MCP server needs configuration variables starts disabled until you enable it, matching plugins installed this way.
  • 1.3.1 fixed installing, reinstalling, and uninstalling a plugin on Windows while one of its MCP servers was running; the CLI now stops the plugin's MCP servers before replacing or deleting its folder and restarts them afterward, and tells you to close any other Antigravity process still holding the plugin open.   • 1.3.2 opens this manager onto the official Antigravity plugin marketplace: browse and install plugins bundling skills, MCP servers, subagents, rules, and hooks, install one from your shell with agy plugin install <plugin-name>@antigravity-plugins-official, or pick + Install from local directory...; the plugin list now opens instantly, an interrupted install never leaves a half-installed plugin, and Windows installs/removals are more reliable.
  • 1.3.3 improved search in the Installed tab: type spaces in a query, press Enter to finish searching, then use Space to toggle the selected plugin and Enter to expand its details; typing again resumes the search.
  • 1.3.4 fixed agy plugin validate, the summary agy plugin install prints, and marketplace previews in this manager's Discover tab leaving out subagents a plugin declares in its root agents.json.
  • 1.3.6 fixed /plugin subcommands such as /plugin List failing with Unknown subcommand when not typed in lowercase; they now work in any case.
