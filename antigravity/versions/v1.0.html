Reference for the Antigravity CLI (agy) and its core extensibility surface. Official documentation at antigravity.google/docs.

TUI & Keys

Keybindings
ItemDescription
#Ctrl+CInterrupt the active model turn or tool execution
  • Pressing twice immediately aborts running background subagents and active commands.
#Ctrl+DExit the interactive CLI session
  • Double Ctrl+D or /exit cleanly terminates session and persists transcript.
#Tab / Shift+TabCycle slash autocompletions or switch agent mode
  • Toggles between default agent mode, plan mode, and review mode when composer is empty.
#↑ / ↓Navigate prompt input history
  • Preserves multi-line formatting and drafts when scrolling through prior turns.
#Ctrl+LClear the terminal screen without resetting context
#Ctrl+RReverse search through previous session prompts
#Ctrl+OToggle expanded thinking traces and tool output
  • Expands inline thinking blocks, diffs, and background task progress streams.

TUI symbols
ItemDescription
#❯Input prompt line where user enters commands
#●Tool invocation marker preceding name and parameters
  • Appends ✓ upon successful tool return or ✗ when tool reports an error.
#✦Antigravity response indicator preceding assistant text
#⠋ / ⠙ / ⠹Animated braille spinner during reasoning and tool wait
#▍Streaming cursor tracking active token generation
#▸ / ▾Collapsible section indicator for thinking and tool diffs

Status & Badges
ItemDescription
#⏱Elapsed turn execution timer
  • Displays generation duration and tool execution seconds for the active prompt.
#🛡 sandboxTerminal sandbox isolation active with restricted commands
#⚡ subagentConcurrent background subagent count badge
  • Shows number of active delegated agents running asynchronously.
#⚠ approvalInteractive confirmation prompt for sensitive actions

Slash (Core)

Session lifecycle
ItemDescription
#/helpDisplay available slash commands and shortcuts
  • Append command name for detailed flags, e.g. /help plan.
#/exit / /quitExit the Antigravity CLI session cleanly
#/clearClear conversation display while preserving context
#/resetReset conversation state and wipe history to start fresh
#/undoRevert the last assistant turn and restore file changes
  • Restores files modified during the turn to their prior state via internal git snapshots.
#/historyView turn history or export session transcript
  • Optionally exports complete interaction log to JSON Lines or Markdown.

Model & execution
ItemDescription
#/modelSwitch active LLM or inspect available model parameters
  • Select from Gemini 3.8 Flash, Gemini 3.1 Pro, Claude Sonnet, or GPT-OSS.
#/modeSet agent execution mode for current session
  • Supports accept-edits, plan, or interactive review mode.
#/effortAdjust reasoning effort level for thinking models
  • Supported levels are low, medium, and high.
#/compactCompress conversation context to preserve token window
  • Summarizes earlier turns while retaining critical architectural decisions.
#/statusShow session telemetry, active model, and token usage

Slash (Tools)

Workflows & planning
ItemDescription
#/planEnter planning mode to draft structured proposals
  • Generates executable plan artifacts before modifying project code.
#/goalRun autonomous long-running task until completion
  • Designed for thorough overnight refactors, exhaustive test runs, or audits.
#/grill-meStart interactive interview to stress-test designs
  • Interviews user relentlessly to resolve architectural ambiguities before coding.
#/boostEnable multi-perspective deep reasoning and verification
#/learnPersist user corrections and patterns for future turns

System & automation
ItemDescription
#/scheduleSchedule recurring cron job or one-shot notification timer
  • Accepts standard 5-field cron syntax or duration seconds with conditional triggers.
#/browserLaunch browser automation to inspect and test web apps
  • Inspects DOM trees, runs automated clicks, and captures console logs and network traffic.
#/teamwork-previewOrchestrate collaborative multi-agent execution pipeline
#/initInitialize project context file in current workspace
  • Scans workspace and generates AGENTS.md or GEMINI.md with conventions.

Lifecycle hooks

  • Runs formatters, linters, or regression tests automatically on modified files.
